# OnOff Sensor

## Download

[Download the latest release](https://github.com/rutgers-caes-research/OnOff_Sensor/releases)

## Install

1. Download and extract the latest source ZIP from **Releases**.
2. Install Arduino IDE and `esp32 by Espressif Systems` version 3.3.10.
3. Open `Firmware/Current/new_xiao_onoff_v6/new_xiao_onoff_v6.ino`.
4. Select **XIAO ESP32-S3** or **XIAO ESP32-C3** and its COM port.
5. Click **Upload**.

Older firmware is available under `Firmware/Archive`.
